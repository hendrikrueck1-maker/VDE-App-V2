# RCD-Typ-Symbole

Nur in den Hilfen (`sym:[…]` in js/erklaerungen-daten.js), nicht im Kartenkopf.

| Datei | Symbol | Kürzel |
|---|---|---|
| `rcd_typ_ac.png`     | Sinus                            | `ac` |
| `rcd_typ_a.png`      | Sinus + pulsierender Gleichstrom | `a` |
| `rcd_typ_f.png`      | Mischfrequenz                    | `f` |
| `rcd_typ_b.png`      | glatter Gleichstrom              | `b` |
| `rcd_typ_b_plus.png` | kHz (bis 20 kHz)                 | `b_plus` |

Kumulativ: AC = ac · A = a · F = a f · B = a f b · B+ = a f b b_plus
